# MCP server icons

One 96 by 96 PNG for each server in the directory, named by the server's id. Each logo is a trademark of its owner and is shown only to tell the servers apart.

Each image was downloaded from the source in the table and decoded. A logo that floats on a transparent background was trimmed of its empty margins and placed on a plain white (or, for a very light logo, dark) square; an icon that already fills its square was kept as it is. Every result was resized to 96 by 96 and written as a PNG.
